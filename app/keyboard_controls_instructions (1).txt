------------------------------------------------------------------------
2. SPECIAL SHORTCUTS
------------------------------------------------------------------------

* Ctrl + Z : Undo last move

------------------------------------------------------------------------
3. MODIFIER SUMMARY
------------------------------------------------------------------------

* Base Key Press      : Standard Clockwise Move / Whole-Cube Rotation
* Shift               : Prime / Counter-Clockwise Move (')
* Ctrl                : Wide Move / 2-Layer Turn (r, f, u, d, l, b)
* Alt                 : Double Turn (2)
* Ctrl + Shift        : Wide Prime Move (r', f', u', d', l', b')
* Ctrl + Alt          : Wide Double Turn (r2, f2, u2, d2, l2, b2)
------------------------------------------------------------------------
4. NEW UI SHORTCUTS
------------------------------------------------------------------------

* Space     : Start inspection / start solve / stop timer
* 1 / 2 / 3 / 4 : Camera Iso / Top / Front / Reset view
* Esc       : Close the mobile quick-action menu
